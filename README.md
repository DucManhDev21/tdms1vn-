# TDMS1VN Frontend

Frontend SPA dành cho Vercel. API được gọi tới Railway Backend qua `https://tdms1vnback-production.up.railway.app/api`.

## Deploy Vercel

Import repository này vào Vercel và deploy như static site. Không cần build command.

- `favicon.ico`
